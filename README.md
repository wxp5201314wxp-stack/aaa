# 仓序 · 进销存系统

中文版单仓库进销存应用，使用 Python 标准库和 SQLite，无第三方依赖。

## 启动

```sh
cd /workspace/aaa
python3 app.py
```

在运行机器的浏览器访问 `http://127.0.0.1:8000`。默认仅监听本机。可通过 `PORT` 改端口，`HOST` 改监听地址；此版本没有身份认证，请仅在可信本机环境使用，不要直接暴露到公网。

## 功能

- 商品档案：唯一编码、分类、单位、采购价、售价、预警库存
- 采购入库与销售出库：往来单位、数量、实际单价、备注
- 事务更新库存与流水，禁止库存不足时出库
- 今日采购销售金额、按商品采购价计算的库存总值、七天数量趋势
- 库存搜索、预警筛选、CSV 导出

初始数据为空，无演示数据。先新增商品，再通过采购入库建立库存。
金额以整数分保存；数量为整数。库存总值是参考采购价乘当前库存，不是会计存货成本核算。
单据日期使用北京时间。此版本不包含登录权限、多仓库、退货、应收应付和财务核算。

## 数据与备份

数据库默认保存至 `data/inventory.db`，重启后保留，可用 `INVENTORY_DB` 指向其他位置。
备份时先停止服务，再复制数据库文件。不要将真实业务数据库提交到 Git。

## 验证

```sh
python3 -m unittest discover -s tests -v
```

测试使用独立临时数据库，验证商品创建、金额保存、出入库、库存不足拦截、错误输入和重启持久化。

## 手机扫描商品条码

- 新增商品中点「扫码填写商品编码」，识别后自动填写商品编码，不自动保存。
- 入库 / 出库单中点「扫码选择商品」，按编码匹配已建档商品，不自动提交单据。
- 页面顶部「扫码查商品」可识别条码并筛选库存。
- 支持 EAN-13、EAN-8、UPC-A/E、Code 128、Code 39、ITF。普通文字编码不属于条码识别；商品名、价格仍需自行填写。
- 手机访问 `http://局域网IP:8000` 时，使用「拍照 / 选择图片」识别；浏览器通常禁止该地址直接启动实时摄像头。实时扫码需要 HTTPS 或本机 localhost，以及摄像头权限。拍照入口是否直接打开相机取决于手机浏览器，也可选择相册照片。
- 图片在浏览器本地处理，不上传。识别后请核对编码，尽量只保留一个完整条码，避免模糊反光。
- 本地附带 html5-qrcode 2.3.8（Apache-2.0，许可证见 `static/vendor/html5-qrcode.LICENSE`），无需 CDN。真实手机摄像头兼容性需在实际设备验证。
